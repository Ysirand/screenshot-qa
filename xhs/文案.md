## 正文

刷题最烦的不是题难,是流程长——截图、切窗口、粘贴、等回复,一套下来思路早断了😮💨

索性自己写了个小工具,现在变成:**点一下 → 拖框选中 → 答案直接出现在桌面上**

📸 **桌面上常驻一个小按钮**
左键点一下进截图,拖框选中题目、松手就开始解题;
按住能拖动、自动吸边;怕手滑还能设成"双击才截图"。

💬 **答案贴在桌面上,不是弹网页**
一个置顶小浮窗,抬眼就能看。**不抢焦点**,不会打断你正在打的字;答完还能接着追问,一键收进错题册。

📚 **做过的题自动攒成册**
截图就是题干,一眼认出是哪道题;自己建分类、写批注、随手搜,全部存本地,秒开。

🆓 **重点:不需要 API Key**
默认直接借你电脑上已经登录的 WorkBuddy 答题;没装也能换成豆包官方 API 或你自己的接口。

💻 Windows / macOS 都能跑,代码全部开源,仓库名 `screenshot-qa`(GitHub 搜 Ysirand 也行,图 5 有二维码)

有问题欢迎提 Issue,看到都会回~
觉得有用的话,给个 Star ⭐ 就是最大的支持
